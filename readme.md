
# 🏷️ lblstdio (Roboflow-Lite)

**lblstdio** — легковесная автономная платформа активного обучения (Active Learning) и полуавтоматической разметки данных для компьютерного зрения в стиле Roboflow.

Платформа реализует замкнутый цикл **Data-Centric AI (Data Flywheel)**: от ручной разметки опорного ядра данных и полуавтоматического переноса меток через сопоставление ключевых точек (SIFT) до фонового обучения моделей YOLOv8, пакетной авторазметки и экспресс-приемки человеком с гарантией чистоты обучающей выборки (Human-in-the-Loop).

---

## 🌟 Ключевые возможности

### 1. Архитектура рабочего пространства (3 логических хаба)
- **Данные (Data Hub):** Обзор здоровья датасета, интерактивный график баланса классов, сводная статистика кадров (*Verified / Pending / Empty*), галерея изображений с фильтрацией по сплитам и статусам.
- **Разметка (Annotation Studio):** Высокопроизводительный холст с фокусом на разметке, виртуализированная вертикальная лента кадров (Filmstrip), навигация без лагов на 4K-изображениях.
- **Модели и Датасеты (Models & Datasets Hub):** Сборка иммутабельных версий датасетов, аугментации, центр управления обучением и реестр моделей с метриками (mAP@50, Precision, Recall).

### 2. Продвинутый Canvas и эргономика разметки
- **Режим быстрого создания:** Режим рисования (`W`) активен по умолчанию с возможностью мгновенного ресайза и перемещения существующих рамок без переключения инструмента.
- **8 маркеров трансформации:** Полноценное изменение размера прямоугольников за углы и стороны с защитой от вылета за границы кадра ($0.0 \dots 1.0$).
- **Quick Class Popover:** При отпускании мыши после рисования рамки прямо возле курсора появляется меню классов — назначение в один клик или клавишами `1`–`9`.
- **Контроль видимости:** Слайдер прозрачности заливки боксов (`0%`–`50%`) и быстрое временное скрытие всех меток по нажатию `H`.
- **Отрицательные примеры:** Отметка пустых кадров кнопкой **«Бэкграунд»** (negative samples) для защиты модели от ложных срабатываний.
- **Сворачиваемые панели:** Скрытие левой ленты (`[`) и правого сайдбара (`]`) для работы на весь экран.

### 3. Полуавтоматический перенос меток (Keypoint Matching)
- Копирование рамки (`Ctrl+C`) на одном кадре и сопоставление на похожем кадре (`Ctrl+Shift+V`).
- Алгоритм **OpenCV SIFT + RANSAC** вычисляет аффинную матрицу трансформации и проецирует геометрию объекта с визуализацией векторов смещения.
- Все перенесенные метки получают статус **`PENDING_REVIEW`** (отображаются пунктиром) и требуют подтверждения человеком.

### 4. Human-in-the-Loop Защитный шлюз (Security Gate)
- **Жесткий инвариант:** В обучающий датасет допускаются **только подтвержденные данные** (`VERIFIED`).
- Попытка собрать версию датасета при наличии хотя бы одной нерассмотренной гипотезы блокируется системой (`UnverifiedDataException`).
- **Экспресс-приемка (Review Bar):** Подтверждение всех предсказаний на кадре клавишей `Space` с автопереходом к следующему кадру; отклонение — клавишей `R`.

### 5. Версионирование датасетов и аугментации
- Неизменяемые (Immutable) снимки версий (`v1`, `v2`) с собственным файлом `data.yaml` и фиксированными файлами аннотаций.
- **Пайплайн Albumentations:** Letterbox-ресайз до 640×640, горизонтальные и вертикальные флипы, повороты, сдвиг (Shear), размытие, шум, вариация яркости/контраста, HSV, Cutout.
- Настраиваемый множитель обучающей выборки ($1\times \dots 5\times$) со случайным распределением Train/Valid/Test.

### 6. Встроенное обучение и авторазметка (Ultralytics YOLO)
- Обучение **YOLOv8n** в отдельном изолированном системном процессе (не блокирует API и интерфейс).
- Поддержка дообучения (Fine-tuning) на основе ранее обученных версий проекта.
- Автоматическое определение устройства (**CUDA GPU / CPU**).
- Мониторинг процесса в реальном времени с графиками Loss и mAP по эпохам, поддержка Early Stopping (*patience*).
- Пакетная авторазметка пула неразмеченных изображений с настраиваемым порогом уверенности.

### 7. Импорт и экспорт
- Импорт одиночных фото, папок или готовых архивов **Roboflow / YOLO** (автоматический парсинг `data.yaml`, `classes.txt` и сопоставление файлов меток).
- Потоковый экспорт всего проекта или конкретной версии датасета в чистый архив структуры Ultralytics YOLO.

## 🛠️ Технологический стек

- **Backend:** Python 3.11+, FastAPI, SQLAlchemy 2.0 (Async), `aiosqlite` (SQLite), OpenCV Headless, Albumentations, Pillow, PyYAML, Ultralytics YOLO.
- **Frontend:** Чистый JavaScript (Vanilla ES6+ модули, нативный reactive `Store` на Proxy), HTML5 Canvas 2D, Tailwind CSS, Lucide Icons.
- **Архитектура:** Чистая архитектура (Clean Architecture / Hexagonal) с изоляцией слоев:
  ```text
  Domain (Entities, Value Objects, Enums)
    └── Application (Use Cases, Ports)
          └── Infrastructure (SQLite, Filesystem, Ultralytics, SIFT)
                └── Presentation (FastAPI Routers, Static Web Server)
  ```

## 🚀 Быстрый запуск

Приложение является полностью автономным, не требует внешних баз данных, Docker или сборщиков фронтенда (Vite/Webpack). Бэкенд автоматически раздает статический фронтенд.

### 1. Клонирование и настройка виртуального окружения

```bash
git clone https://github.com/your-username/lblstdio.git
cd lblstdio/backend

python -m venv .venv
# Активация на Linux/macOS:
source .venv/bin/activate
# Активация на Windows:
# .venv\Scripts\activate
```

### 2. Установка зависимостей

```bash
pip install -e .
# или
pip install -r <(python -c "import tomllib; f=open('pyproject.toml', 'rb'); [print(d) for d in tomllib.load(f)['project']['dependencies']]")
```

*(Для запуска тестов дополнительно установите dev-зависимости: `pip install pytest pytest-asyncio pytest-cov httpx`)*

### 3. Запуск приложения

```bash
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Откройте в браузере:
- **Интерфейс приложения:** [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **Интерактивная документация API (Swagger):** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## 🔄 Цикл работы (Active Learning Workflow)

```text
 1. Создание проекта & Импорт фото (Data Hub)
                  │
                  ▼
 2. Ручная разметка ядра 20-40 кадров (Canvas Studio)
    ├── Прямоугольники (Quick Class Popover)
    ├── Перенос меток через SIFT (Ctrl+C / Ctrl+Shift+V)
    └── Отметка фоновых кадров («Бэкграунд»)
                  │
                  ▼
 3. Сборка версии Dataset v1 (Проверка HITL-шлюза + Аугментации)
                  │
                  ▼
 4. Запуск обучения Model v1 (YOLOv8n, live-графики loss/mAP)
                  │
                  ▼
 5. Авторазметка 100+ сырых кадров с порогом уверенности
                  │
                  ▼
 6. Экспресс-верификация человеком через Space (Приемка) / R (Отказ)
                  │
                  ▼
 7. Дообучение Model v2 (Цикл замыкается с ростом mAP)
```

## ⌨️ Горячие клавиши (Hotkeys Cheatsheet)

| Клавиша | Контекст | Действие |
| :--- | :--- | :--- |
| `W` | Холст | Активировать режим рисования рамки (`DRAW`) |
| `V` | Холст | Активировать режим выбора (`SELECT`) |
| `1` – `9` | Студия | Назначить класс выделенному боксу / выбрать активный класс |
| `Space` | Верификация | **Подтвердить все** предсказания кадра (`VERIFIED`) и перейти далее |
| `Space` *(удерж.)* | Холст | Панорамирование изображения (Pan) |
| `R` | Верификация | **Отклонить все** неподтвержденные рамки на кадре |
| `D` или `→` | Навигация | Сохранить и перейти к следующему кадру |
| `A` или `←` | Навигация | Сохранить и перейти к предыдущему кадру |
| `Ctrl + S` | Холст | Принудительное сохранение разметки |
| `Ctrl + C` | Выделение | Скопировать геометрию бокса для переноса точек |
| `Ctrl + Shift + V` | Кадр | **Вставить через сопоставление точек (SIFT)** |
| `Delete` / `Backspace` | Выделение | Удалить выделенный бокс |
| `H` | Холст | Скрыть / показать рамки (инспекция пикселей под разметкой) |
| `[` / `]` | Студия | Свернуть/развернуть левую ленту кадров / правый сайдбар |
| `F` | Холст | Сбросить зум и центрировать изображение (Fit to Screen) |
| `Колесико мыши` | Холст | Зум с фокусом на позицию курсора мыши |

## 📁 Структура проекта

```text
lblstdio/
├── backend/
│   ├── app/
│   │   ├── domain/               # Чистые сущности (Image, Annotation, Project, DatasetVersion)
│   │   ├── application/          # Сценарии использования (Use Cases) и порты (Interfaces)
│   │   ├── infrastructure/       # SQLite, Ultralytics Trainer/Predictor, SIFT Matcher, Albumentations
│   │   ├── presentation/         # FastAPI роутеры, схемы DTO, DI-контейнер
│   │   └── main.py               # Точка сборки FastAPI и раздачи статики
│   └── tests/                    # Unit, Integration и E2E тесты (pytest)
├── frontend/
│   ├── css/styles.css            # Стили темной темы, кастомные скроллбары
│   ├── js/
│   │   ├── components/           # Модули интерфейса (dataHub, canvas, filmstrip, modelsHub...)
│   │   ├── store.js              # Реактивное состояние (Proxy Store)
│   │   ├── router.js             # Хэш-роутер субвкладок
│   │   ├── hotkeys.js            # Диспетчер клавиатурных сокращений
│   │   └── api.js                # HTTP-клиент к REST API
│   └── index.html                # Семантическая разметка и модальные окна
└── storage/                      # Локальные файлы картинок, датасетов и весов (создается при запуске)
```
